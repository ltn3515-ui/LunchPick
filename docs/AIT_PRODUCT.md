# 점메픽 (LunchPick) — Product

## Core Value
"점심 메뉴 고민을 1초 안에 해결" — 토스 앱을 점심시간 직전~점심시간에 여는 직장인이 메인 타겟.

## Category
- **UTILITY** (1차 분류 확정)
- LOCATION 요소(주변 식당 연계)는 MVP에 **미포함**. 메뉴 추천은 하드코딩된 로컬 데이터셋 기반이며 위치 권한을 요청하지 않는다.

## Mini Scope
| 단계 | 내용 |
|---|---|
| 진입 | 로그인 없이 Home 화면 즉시 노출 |
| 핵심 행동 | "오늘 뭐 먹지?" 버튼 탭 (선택: 카테고리 필터) |
| 결과 | 메뉴 1개를 큰 카드로 노출 |
| 저장/공유/재사용 | 로컬 저장(History), 네이티브 공유 시트, 재방문 시 History 재열람 |

## MVP 범위
- 포함: Home / Result / History 3화면, 카테고리 필터(한식·중식·일식·양식·분식), 로컬 저장, 공유
- 제외(성장 기능 후보): 주변 식당 쿠폰 연계, 토스페이 결제 혜택 연계, 광고(IAA), 인앱결제(IAP), 리뷰 요청(requestReview)

## 후속 확장 지점 (아키텍처만 열어둠, 이번 스프린트 미구현)
1. **위치 기반 추천**: 현재 `pickRandomMenu(category?)`가 `MenuItem[]` 배열만 입력받는 순수 함수이므로, 추후 `Location` API로 좌표를 얻어 주변 식당 데이터를 병합한 소스로 교체 가능
2. **쿠폰/결제 연계**: Result 화면의 `result-actions` 영역에 버튼 슬롯 추가만으로 확장 가능하도록 컴포넌트 분리해둠
